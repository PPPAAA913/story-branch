# 写作材料包（王司恺）

面向 Story Branch v0.5.1 的**六阶段独立稿件**模型，不是旧版的单文档模型。材料分六块：

1. `简报-001/002/003.md`：三份原创测试简报，写清具体英语地区、题材、时长、演员与场地限制。
2. `模板包-v1.md`：六个阶段的提示词模板，按“阶段－目的－版本”命名，可直接在“提示词库 → 修改并另存”里创建。
3. `演示案例-CASE-001.md`：**已选定的演示案例**，按“阶段、模板标题、正文、输入例子、预期结果、已知问题”整理，可直接提交或照着演示。
4. `写作方法与适配.md`：五项开源写作方法、短剧适配规则、阶段映射，以及模板与方法包的分工。
5. `验收与对照.md`：每阶段验收点、片段记录表，以及和吕兴治的对照试写/盲评流程。
6. `交接与使用说明.md`：上线后怎么把模板和演示项目落到共享服务，以及各角色分别怎么用。

## 使用顺序

1. 用 `wang_sikai` 账号登录本机服务，先跑**样例模式**，只验证流程，不评价写作质量。
2. 新建项目，粘贴一份简报，确认“创作简报”阶段。
3. 在“提示词库”里用 `模板包-v1.md` 的正文创建自定义模板，命名照抄建议标题。
4. 每个阶段：选模板 → 生成本轮 → 人工改到可接受 → 保存 → 确认本阶段。
5. 换方向或改上游前先建分支；审阅用“只审阅”，不要直接让它改稿。
6. 把满意/不满意的**实际片段**记到 `验收与对照.md`，不要只写“好/不好”。

## 边界

- 这些简报是原创测试材料，不是市场调研，也不能写成“行业验证”。
- 样例模式输出是固定文本，不能用来给模型质量打分。
- 真实 API 由彭奥配置；普通成员界面没有“模型设置”。
- 模板只写内容约束，不改后端；写作方法包（人物、节拍、场景、对白、审阅）由服务端自动注入，模板不要重复抄一遍。
